# 9bhk design context

The existing application UI is the visual baseline. Use forest green (#18352B),
warm white (#FCFBF8), cream (#F7F3EA), and restrained terracotta (#C86B45).
Use Manrope for interface text and Instrument Serif for editorial headlines,
with Tamil/Telugu font support. Keep property photography, rounded cards,
readable prices, accessible focus rings, mobile safe areas, and existing
navigation. Support browser zoom, keyboard use, reduced motion, and honest
loading/error/empty states. Financial statuses must come from persisted server
data. Never invent review counts, verification, payout balances, or guarantees.
New feature controls should fit the existing Next.js components.
