# 9bhk design context

Derived from the existing application, not a generated Stitch screen.

## 6. Design system notes for Stitch generation

Use 9bhk's current forest green (#18352B), warm white (#FCFBF8), cream
(#F7F3EA), and restrained terracotta (#C86B45). Use Manrope for interface text
and Instrument Serif for editorial headlines, with Tamil/Telugu font support.
Keep the calm property photography, rounded cards, readable prices, accessible
focus rings, mobile safe areas, and existing navigation. Support browser zoom,
keyboard use, reduced motion, and honest loading/error/empty states. Financial
statuses must come from persisted server data. Never invent review counts,
verification, payout balances, or guarantees. New screens should fit the existing
Next.js components rather than introduce a separate static HTML application.
