# Prompt 07 — Property Detail

Build the property detail screen.

## Structure
- immersive image gallery
- back/share/favorite actions
- title
- location
- rating and review count
- guests / bedrooms / beds / bathrooms
- description
- amenities
- gallery
- reviews summary + review list
- map/location
- house rules
- cancellation policy
- sticky mobile booking bar

## Sample content
Title: `Palm Grove Private Farmhouse`
Location: `ECR · Near Mahabalipuram`
Summary: `8 guests · 3 bedrooms · 4 beds · 3 bathrooms`
Description: `A quiet private escape surrounded by palms, open lawns and a pool — made for slow mornings and long evenings.`
CTA: `Check availability`

## Rules
Photography first. Keep copy concise. Avoid giant walls of text. Map can show approximate location for privacy until booking where appropriate.
Stop after this task.
