# Prompt 02 — Build the Shared Design System

Read `../DESIGN_SYSTEM.md` and the reference images before coding.

## Task
Create the reusable visual system before building feature screens.

### Create
- typography tokens
- color tokens
- spacing tokens
- radius tokens
- shadow tokens
- button variants
- input variants
- pill/chip
- icon button
- card primitives
- bottom sheet primitive
- mobile bottom navigation
- section heading
- rating badge
- price block
- image container
- skeleton loaders
- empty state
- error state

### Visual requirements
Use warm cream/warm-white backgrounds and deep forest for primary actions. Keep content airy. Rounded corners should feel soft, not playful. Avoid excessive drop shadows. Property photography must remain the strongest visual element.

### Components to standardize
`PropertyCard`, `SearchField`, `FilterChip`, `AmenityItem`, `PrimaryButton`, `SecondaryButton`, `IconButton`, `BottomNav`, `Sheet`, `PriceSummary`, `RatingBadge`, `ImageCarousel`, `EmptyState`.

### Acceptance
Create a `/design-lab` internal route showing every component and state at mobile width.
Do not implement product-specific data fetching yet.
Stop after completing this task.
