# Prompt 14 — Admin Screens

Build the minimum admin workspace.

## Screens
- Admin dashboard
- Property review
- User/host management
- Booking management
- Verification queue

## Dashboard
Totals for properties, users, bookings, pending reviews.

## Property review
Show property photos, details, host, submitted documents/status, and actions:
`Approve`
`Request changes`
`Reject`

## Verification queue
Separate host verification from property verification.

## Security
Admin-only server and RLS access. Never rely only on hidden navigation for security.
Stop after this task.
