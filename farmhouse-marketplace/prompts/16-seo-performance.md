# Prompt 16 — SEO, Performance, Accessibility

## SEO
Create indexable public URLs:
`/farmhouses/[city]/[slug]`

Dynamic metadata:
title
description
OG image
canonical

Add structured data for public property pages where valid.

## Performance
- Use Server Components by default.
- Client components only when interactivity requires them.
- Use responsive image sizes.
- Lazy load non-critical media.
- Avoid serial data waterfalls.
- Prefetch only where it improves navigation.

## Accessibility
- semantic HTML
- labels
- focus states
- keyboard support
- reduced-motion support
- 44px minimum touch target
- adequate contrast

Stop after this task.
