# Prompt 17 — Seed Data and Realistic Content

Create safe development seed data for at least 12 farmhouse properties across:
Chennai
ECR
Mahabalipuram
Chengalpattu
Kanchipuram
Pondicherry

Each property should include:
- realistic title
- concise description
- guest capacity
- bedrooms/beds/bathrooms
- price
- 5–8 amenities
- 3–8 image references/placeholders
- rating/review count only where the schema supports it
- sample availability

Example titles:
Palm Grove Private Farmhouse
Mango Orchard Retreat
Blue Horizon Farm Stay
Lakeview Courtyard
Coconut Grove Escape
Sunset Fields Farmhouse

Content should feel premium and local without making unverifiable claims about real properties.
Stop after this task.
