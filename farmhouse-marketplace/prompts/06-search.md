## UX
- Results should feel editorial, not like a spreadsheet.
- Keep filter chips visible after selection.
- Filter sheet should be a mobile bottom sheet and a side/center panel on desktop.
- Show result count only when useful.
- Preserve search state across navigation.
- URL should encode shareable search state where practical.

Acceptance: keyboard accessible, mobile first, no layout jumps, loading and empty-result states included.
