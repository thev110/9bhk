# Farmhouse Rental Marketplace — Product Spec

## Core promise
Find a beautiful farmhouse for a short escape, or list your farmhouse for guests.

## Primary user types
### Guest
Discover → Search → Filter → Property → Availability → Booking → Trip → Review

### Host
Dashboard → Add Property → Details → Photos → Amenities → Pricing → Availability → Publish → Bookings → Earnings

### Admin
Dashboard → Property Review → User/Host Management → Booking Management → Verification Queue

## Primary guest copy
- Home heading: `Where do you want to escape?`
- Search placeholder: `Search places, areas or farmhouses`
- Featured heading: `Made for slow weekends`
- Nearby heading: `Escapes near you`
- CTA: `Check availability`
- Booking CTA: `Reserve`
- Saved empty state: `Save places you want to come back to.`
- Trips empty state: `Your next escape starts here.`

## Suggested initial geography
Chennai, ECR, Mahabalipuram, Chengalpattu, Kanchipuram, Pondicherry.

## Brand tone
Warm, calm, premium, concise, conversational. Avoid generic real-estate jargon. Prefer “stay”, “escape”, “farmhouse”, “host”, “trip” over “unit”, “inventory”, “listing” in guest-facing UI.
